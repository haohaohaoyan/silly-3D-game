# silly 3d game i'm working on

project for hack club flavortown
i'm planning on some portal-type exploration and titanfall 2/ultrakill style movement
it's not finished yet, but you can check out what's already available in releases.

## movement:
- regular sliding (you can't change direction but you accelerate and preserve speed)
- wall-sliding and walljumping for more verticality and movement options (and more SPEED)
- a grappling hook that functions similar to ultrakill's, but can hook onto anything within 30m of you and lets you keep the momentum on grappling complete
## level design (so far):
- death and checkpoint system, designed to be used like celeste's screen transitions and checkpoints
- screenwipe when you die/transition menus
- a bit of a start to the first chapter's entrance, but not really too much.
## other:
- a main menu, (maybe?) placeholder name, and level select
- settings and pause menu
- some bad sfx
